# Jashwanth Kumar — Portfolio

A bright, responsive personal portfolio built with HTML, CSS and JavaScript.

## Files
- index.html
- style.css
- script.js

## Publish with GitHub Pages
1. Create a public repository named `portfolio`.
2. Upload the three files to the repository root.
3. Go to Settings → Pages.
4. Select `Deploy from a branch` → `main` → `/ (root)`.
5. Save and open `https://YOUR-USERNAME.github.io/portfolio/`.
